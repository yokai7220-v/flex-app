# Гибкость — PWA по годовому плану Меррика

Vite + React + TS + vite-plugin-pwa. Данные только в IndexedDB на устройстве (без сервера). Деплой — GitHub Pages через `.github/workflows/deploy.yml` на push в `main`, адрес `https://yokai7220-v.github.io/flex-app/`.

## Команды

- `npm run dev` — дев-сервер (`/flex-app/`)
- `npm run build` — проверка типов + сборка; это основная проверка перед коммитом
- `npm run check-videos` — проверить, что все YouTube-ID из `src/data/program.ts` живы
- Скриншоты состояний: дев-сервер на 5199, затем Playwright MCP `browser_run_code_unsafe` со скриптом из `.playwright-mcp/` (репозиторий — разрешённый корень), скриншоты в `/tmp/flex-*`

## Правила

- Весь контент (уровни, рутины, видео, тексты) — только в `src/data/program.ts`; экраны контент не хардкодят.
- Не класть артефакты проверки внутрь проекта под .gitignore — агент не может их прочитать; писать в `/tmp`.
- Не восстанавливать вложенный маршрут при старте (`nav.tsx` открывает корень вкладки), иначе «Назад» после перезагрузки ведёт в никуда.
- Не вызывать `navigator.share` после долгой асинхронной работы — iOS теряет «жест пользователя»; бэкап собирается первой кнопкой, отдаётся второй.
- Прогресс — только календарь и фото: счётчики, «выполнение плана» и график по неделям намеренно убраны, не возвращать.
- Новые зависимости — только версии, опубликованные больше 7 дней назад, с `--save-exact`.
- Уровни называть по лестнице Меррика (Basic, Basic+, Intermediate, Advanced) — свои имена не выдумывать.
- «Замер» — не страница и не подвид: замер = фото (`lastMeasure` смотрит на дату последнего фото). Видео про замер — разделом «Замер» внизу «Фото» (`testRoutine.videos`); напоминание с «Сегодня» ведёт на `{ tab: 'progress', sub: 'photos' }`.
- Прогресс плана показывать только по уровням: «пройденный» уровень = раньше текущего в списке `levels` или все его критерии отмечены — это `levelDone` в `Program.tsx`, метка ✓ в пилюле (`Seg` опция `done`) и в заголовке карточки. Шкалу по времени не строить — переходы ручные и по критериям, календарь ничего не значит.
- Перед браузерной проверкой новой сборки снимать регистрацию service worker и чистить `caches` — `vite preview` отдаёт закэшированный старый билд.
- Playwright MCP разрешает `filename` только внутри репозитория — разовые скрипты класть в `flex-app/.playwright-mcp/` и удалять после прогона; скриншоты писать в `/tmp`. Между прогонами чистить IndexedDB транзакцией (`clear()` по всем сторам), не `deleteDatabase` — приложение держит соединение открытым, удаление блокируется и скрипт виснет. Controlled input React не реагирует на `el.value =` — ставить нативным сеттером `Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el, v)` + событие `input`. Если любой инструмент отвечает «does not handle the modal state» — висящий file chooser отменить `browser_file_upload` без `paths`; если chooser рецидивирует (очередь штуками), закрыть страницу `browser_close` и начать заново. `click()` по `<summary>` под фиксированной панелью виснет — раскрывать `details.open = true`.
- Уровни в UI показывать только именем (`level.short`), номер `level.num` не выводить нигде, и в текстах тоже (не «с третьего уровня»).
- Тяжёлые рутины показывать слотом, а не «N раз в неделю»: пилюля «Тяжёлая А/Б/С» (`kindLabel` + `slot`) и цикл `level.rotation` буквами `.rotl` в мета-строке, своё место подсвечено акцентом; `freq` у тяжёлых не выводится.
- Тяжёлая не по расписанию, а по требованию: на «Сегодня» всегда карточка «Добавить тяжёлую», шторка предлагает `nextHeavy` первым и остальные ниже, тап по карточке сразу пишет лог (отметка в календаре мгновенная). Расписания дней недели и силовых дней нет, `isStrengthDay`/`isHeavyDay`/`planToday` не возвращать; из настроек остался только `heavyMode` (влияет на заметку про разминку).
- Списки упражнений показывать только в карточке видео (`Video.steps` + шеврон `.vcaret` в `VideoList`); секцию «Упражнения» в `RoutineDetail` не возвращать: `Routine.steps` оставлен в данных нарочно, но не рендерится. Списки расшифрованы по автосубтитрам — при сомнении сверять формулировки с видео. Разминку тяжёлой в режиме «между» показывать заметкой `WARMUP_STEP`, если первое видео не начинается с «Разминка».
- Отметки за прошлые дни — в шторке дня календаря: там список неотмеченных рутин текущего уровня и замер; «Отметить за другой день» в детали рутины — для произвольной даты и рутин других уровней.
- Ячейку календаря держать фиксированной высоты: цифру центрировать флексом, точки — абсолютом у нижнего края; точки в потоке сдвигают цифру, а у самого края выглядят прижатыми.
- В детали рутины не дублировать то, что уже на карточке (тип, уровень, частота, длительность) — шапка детали без чипов.
- Называть рутину содержанием («Всё тело», «Наклон»), а не типом или частотой — тип показывает чип `kindLabel`, частота уже есть в мета-строке или заголовке секции, повтор слова читается дублем; на «Сегодня» у лёгкой частоту скрывает проп `hideFreq`.
- Тексты писать сухими: без оправданий, эпитетов и обнадёживающих хвостов — лишнее вычищено раз, повторять не надо.
- Тире «—» в текстах не ставить, кроме словаря «термин — определение»: связки через тире — главный признак ИИ-текста; вместо них точка, двоеточие, запятая.
- Одно понятие — одно слово: «лёгкая» и «тяжёлая»; не «блок», «сессия», «финишер», «смазка» — разные слова читаются как разные вещи.
- Английское имя упражнения писать, только если нет устойчивого русского (Jefferson curl, Couch stretch, Pancake); английских дублей в скобках не ставить.
- Один совет — в одном месте: «как снимать фото» живёт в пустом состоянии «Фото»; при правке текста искать повторы по всему `src`.
- `Seg` по роли: `variant="tabs"` — разделы, `variant="switch"` — выбор режима, без варианта — прокручиваемые ленты (уровни, позы); одну форму на всё не использовать.
- Зелёный (`--accent`) только для действий и «сделано»; данные (дозировки) не красить — иначе выглядят ссылками.
- Вступления и заметки — `.lead` / `.note` без карточки; `.card` только для предметов (рутина, фото, видео, календарь).
- Не ставить легенду-пояснение под графиком или сеткой — подписывать прямо на элементе.
- На «Сегодня» задачи дня — первыми; напоминания (замер, бэкап, установка) и разгрузка не выше них (разгрузка — метка в шапке).
- «Теория» — вложенный экран `go({ tab: 'program', level: 'theory' })` со строкой внизу «Программы», не таблетка в ленте уровней.
- Видео открывать через `openVideo` в `VideoList` (схема `youtube://` / `vnd.youtube:` + фолбэк на веб через 2 с): из PWA обычная https-ссылка идёт во встроенный браузер, а не в приложение YouTube; не возвращать голую ссылку.
